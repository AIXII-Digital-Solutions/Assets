# Airline Logo Assets

Vector (SVG) logo assets for airline and aviation brands, redrawn from original raster sources.

This repository contains **15 brands**. Each brand ships three files: a **transparent SVG master**, a **white-background SVG variant**, and the **original raster source**.

## Repository layout

```
airline-logos/
├── README.md
├── manifest.json        # machine-readable index (files, dimensions, colors)
├── svg/                 # vector assets
│   ├── <brand>.svg          transparent master
│   └── <brand>_white.svg    white background
└── source/              # original raster sources (PNG / JPG)
    └── <brand>.<ext>
```

All SVGs use a normalized 1000-unit viewBox, so they scale to any size with no quality loss. Filenames are lowercase `snake_case`; every SVG shares a base name with its source in `source/`.

## How these were produced

The SVGs were generated by tracing the original raster sources with a custom Bézier vectorization pipeline (Catmull-Rom curve fitting with corner preservation and even-odd holes), chosen because no off-the-shelf tracer was available in the build environment. Each logo used a strategy matched to its artwork:

- **Flat single-color** marks (e.g. BBN Airlines, HelloJets, Klasjet, Sundair, SCAT Airlines) were traced as solid shapes.
- **Two-tone** wordmarks (ASCEND Airways / Malaysia) were separated into a navy layer and a steel-blue accent layer.
- **Gradient** marks (Avion Express, AviaAM orbit, BBN Indonesia, TradeAir band) keep a clean traced shape with a fitted linear/radial gradient; fade-to-white regions sample the gradient over a dilated region so the falloff reads correctly while edges stay crisp.
- **Hue-split** artwork (FitsAir) separates navy and red elements; the halftone swoosh resolves to a clean two-color transition.
- **Faceted low-poly** marks (SmartLynx ×3) posterize the star into flat facets with sharp corners; the star is identical across the three, only the country word differs.

Halftone blends and within-facet shading are intentionally simplified to clean vector regions rather than reproduced dot-for-dot — the right trade for a crisp, scalable master asset.

See `manifest.json` for the per-brand file map, source dimensions, and exact colors.
